# DavidAgent 架构决策记录 (ADR)

## 概述
本文档记录了DavidAgent数字分身系统从概念到工业级部署的完整架构演进过程，包含所有关键设计决策、技术选型理由和实现方案。

## 时间线

### 第一阶段：双脑架构基础 (初始设计)
- **核心理念**：Qwen（右脑）负责创造性任务，Gemini（左脑）负责逻辑性任务
- **通信机制**：虚拟胼胝体（黑板模式）实现组件间解耦通信
- **记忆系统**：ChromaDB作为长期记忆，支持相关性阈值和优雅降级
- **执行器**：WordPress发布引擎，具备完整的重试机制

### 第二阶段：元认知与情景记忆 (G老师建议1)
- **情景记忆**：SQLite数据库存储完整任务生命周期快照
- **可视化控制台**：Streamlit Dashboard提供人类复盘界面
- **夜间反思**：自动分析失败任务，生成避坑指南
- **自我进化**：动态更新右脑System Prompt，实现持续优化

### 第三阶段：高性能与高可用性增强 (G老师建议2)
- **SQLite WAL模式**：启用Write-Ahead Logging支持高并发读写
- **Streamlit缓存**：@st.cache_data实现按需加载，防止UI卡死
- **规则剪枝**：夜间反思强制压缩规则到10条以内，防Prompt膨胀
- **RLHF反馈**：三维度打分（逻辑/网感/排版）指导精准微调

### 第四阶段：工业级生产就绪 (G老师建议3)
- **防爆盾**：全局信号量+指数退避熔断保护，防API击穿
- **遗忘曲线**：ChromaDB时间衰减，保持记忆新鲜度
- **主动引擎**：每周图谱涌现，主动发现行业趋势
- **Token经济学**：成本可视化监控，支持智能模型选择

## 技术栈决策

### 数据库选择
- **SQLite**：轻量级、零配置、支持WAL模式，适合单机部署
- **ChromaDB**：向量数据库，支持语义搜索和时间衰减

### Web框架
- **Streamlit**：快速构建数据可视化界面，支持缓存和懒加载

### 并发模型
- **asyncio**：Python原生异步框架，配合信号量实现流量控制

### AI模型
- **Qwen-Coder-Plus**：右脑，擅长创造性写作和技术总结
- **Gemini**：左脑，擅长结构化数据提取和事实验证
