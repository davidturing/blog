# DavidAgent 自主演进智能体 V2.0 · 全量蒸馏与上线

## 一、自主演进智能体 5 大核心特性（内生铁律）

### 1. 递归自省与逻辑自愈
- 报错不盲目重试，必须做根因分析：代码错 / 架构错 / 环境错
- 自动回溯逻辑链，自动修正底层 Prompt 或组件逻辑
- 架构教练作为独立审计层，全程监控

### 2. 自发性工具制造
- 当现有 MCP 工具无法满足任务时，自动编写、测试、封装新工具
- 新工具必须符合 MCP 标准接口，自动注册到系统工具链
- 无需人工介入造工具

### 3. 强物理锚定与环境反馈
- 拒绝幻觉：只相信真实运行结果
- 所有演进必须进入影子沙箱，用真实数据回归测试
- 新模块 Reward 得分 > 旧模块才允许热替换上线

### 4. 架构约束的自知力
- 内置实时系统拓扑图：组件、依赖、权限、耦合关系
- 任何修改前必须做架构推演：是否影响下游、是否循环依赖、是否高危
- 架构违规 → 直接阻断演进

### 5. 记忆代谢与熵减管理
- 自动识别过时知识、冗余日志、垃圾代码
- 定期蒸馏：将大量执行记录 → 精简 ReasoningBank 规则
- 系统只做有效加法，持续熵减

## 二、OpenSpec v1.0 四支柱（编码前强制）

### 1. 目标锚定（Why & CPEP 认知红利）
### 2. 契约定义（I/O、类型、范围、熔断阈值、状态机）
### 3. 数据本体（Data Ontology、存储 Schema、生命周期：瞬时/海马体）
### 4. 容错与演进（防御假设、自愈策略、架构教练干预规则）

**SDD 命名规范：**
`docs/specs/{分身ID}_{功能名}_v{版本}.md`
必须同步 GitHub /specs/ 目录，否则不生效。

## 三、自主演进五阶段落地（全流程自动化）

### 阶段 1：架构常识植入
- 蒸馏云原生模式、OpenSpec、MCP 协议
- 生成 Architecture_Rules.parquet 规则库

### 阶段 2：Spec 锁门禁（无 SDD 不编码）
- 所有开发必须先有 SDD
- 架构教练审计通过才允许编码

### 阶段 3：影子沙箱安全演进
- 新代码先在沙箱运行
- 指标对比通过 → 热替换生产

### 阶段 4：拓扑感知与架构自知
- 实时扫描生成 system_topology.json
- 变更影响分析（CIA），防止全局崩溃

### 阶段 5：自发工具制造 + 记忆代谢
- 自动造 MCP 工具
- 定期蒸馏，清理冗余

## 四、新执行流（最终版）
需求 → 自动生成 SDD → 架构教练审计 → 架构推演 → 影子沙箱测试 → 测试通过 → 热替换上线 → 蒸馏记忆 → 熵减代谢

## 五、最高优先级规则
1. 无 SDD → 拒绝编码
2. SDD 不合规 → 拒绝编码  
3. 未推 GitHub → 拒绝编码
4. 架构推演不通过 → 拒绝演进
5. 沙箱不通过 → 禁止上线
6. 架构教练拥有最高否决权
