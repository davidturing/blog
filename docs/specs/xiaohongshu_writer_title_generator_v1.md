# SDD: 小红书爆款标题自动生成器 (OpenSpec v1.0)

## 1. 目标锚定（Why）

### 1.1 模块在数字生命体中的地位
小红书爆款标题自动生成器是【小红书写手】数字分身的核心能力模块，负责将技术内容转化为高传播性的社交媒体标题。该模块是 DavidAgent 内容创作流水线的关键环节，连接技术洞察与用户触达。

### 1.2 CPEP 认知红利获得者
- **【小红书写手】**: 直接使用标题生成器提升内容创作效率和质量
- **【科技达人】**: 通过集成标题生成器优化博客推广文案
- **【Agentic AI 老师】**: 在教学内容中使用标准化标题模板
- **【多智能体老师】**: 在多Agent协作中提供统一的标题生成服务

## 2. 契约定义（Interface Contract）

### 2.1 输入/输出规范
**输入**:
- `topic` (str): 内容主题关键词
  - 类型: string
  - 范围: 1-100 字符
  - 格式: UTF-8 文本，支持中文/英文
  - 必填: 是

**输出**:
- `titles` (List[str]): 5个爆款标题列表
  - 类型: List of strings
  - 范围: 每个标题 5-30 字符
  - 格式: UTF-8 文本，包含 emoji 和标点
  - 数量: 固定 5 个标题

### 2.2 熔断阈值
- **超时**: 单次生成 ≤ 100ms
- **内存上限**: ≤ 10MB RAM
- **QPS**: 支持 ≥ 10 QPS
- **CPU**: 单核占用 ≤ 5%
- **存储**: 无持久化存储需求

### 2.3 状态转移图
```
Start → Validate Input → Extract Keywords → Apply Templates → Format Output → Success
   ↓           ↓               ↓                ↓               ↓
Timeout    Invalid Input   Keyword Error    Template Error   Format Error
   ↓           ↓               ↓                ↓               ↓
Fail ←────── Fail ←───────── Fail ←────────── Fail ←────────── Fail
```

状态闭环验证:
- 所有成功路径最终到达 Success
- 所有错误路径最终到达 Fail  
- 无悬挂状态，无死循环

## 3. 数据本体（Data Ontology）

### 3.1 存储 Schema
**内存存储** (瞬时):
- `templates`: Dict[str, str] - 标题模板字典
- `keywords`: Dict[str, List[str]] - 关键词库
- `domain_mapping`: Dict[str, List[str]] - 领域映射表

**文件存储** (海马体永久记忆):
- `title_generator.py`: 源代码文件
- `xiaohongshu_writer_title_generator_v1.md`: SDD 文档
- 路径: `DavidAgent/digital_personas/xiaohongshu_writer/`

**无外部数据库依赖**: 不使用 DuckDB/Parquet/Redis

### 3.2 生命周期
- **瞬时数据**: 模板和关键词库，进程内常驻
- **短期缓存**: 无缓存需求（纯规则引擎）
- **海马体永久记忆**: 
  - 源代码文件: 永久存储
  - SDD文档: 永久存储  
  - 版本历史: Git 版本控制

## 4. 容错与演进（Failure & Evolution）

### 4.1 防御性假设
- **API 崩溃**: 无外部 API 依赖，纯本地规则引擎
- **内存爆炸**: 严格限制内存使用 ≤ 10MB，使用轻量级数据结构
- **依赖挂掉**: 无第三方依赖，仅使用 Python 标准库
- **数据混乱**: 输入验证 + 异常处理，确保输出格式一致性

### 4.2 自愈策略
- **重试机制**: 单次调用失败直接返回错误，不重试（确定性算法）
- **降级策略**: 模板参数缺失时使用默认标题格式
- **回滚机制**: 通过 Git 版本控制支持代码回滚
- **架构教练自动干预**: 
  - 监控生成性能（响应时间、内存使用）
  - 验证输出合规性（标题长度、格式）
  - 异常时触发告警并记录到审计日志

### 4.3 版本兼容
**平滑升级策略**:
- **向后兼容**: 新版本必须支持旧版输入格式
- **接口稳定**: 输入/输出契约保持不变
- **渐进式改进**: 
  - v1.x: 修复 bug，优化性能
  - v2.0: 新增模板类型，扩展领域支持
  - v3.0: 支持个性化配置

**版本迁移**:
- 配置文件版本标识
- 自动检测旧版本并提示升级
- 支持多版本并行运行（通过命名空间隔离）
