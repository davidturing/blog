# SDD: 小红书爆款标题自动生成器

## 1. 功能概述
为【小红书写手】数字分身开发智能标题生成器，基于内容主题自动生成高点击率小红书标题。

## 2. 核心需求
- 输入：内容主题关键词
- 输出：5个不同风格的爆款标题
- 支持领域：AI、架构、程序员效率、工具技巧
- 字符限制：每个标题 ≤ 30字

## 3. 标题模板
### 3.1 痛点解决型
"🔥{痛点}：{解决方案}！"

### 3.2 数字量化型  
"🎯{数字}{动作}，{效果}"

### 3.3 内幕揭秘型
"💡内部揭秘：{核心价值}？"

### 3.4 效率提升型
"🚀{前后对比}，{秘密武器}"

### 3.5 颠覆认知型
"✨意外发现：{惊人效果}！"

## 4. 关键词库
- 痛点词：崩溃、踩坑、浪费、低效、复杂、头疼
- 数字词：3步、5分钟、10倍、99%、一键、秒级  
- 效果词：爆款、涨粉、效率翻倍、省时省力、惊艳
- 权威词：米其林、大厂、专家、秘籍、内部、独家

## 5. 技术实现
- 语言：Python
- 依赖：无外部依赖（纯规则引擎）
- 性能：单次生成 < 100ms
- 内存：≤ 10MB

## 6. 验收标准
- [ ] 5种标题模板完整实现
- [ ] 支持所有指定领域关键词
- [ ] 标题长度符合小红书规范
- [ ] 无重复标题生成
- [ ] 通过架构教练审计

## 7. 使用方式
指令格式：`/xhs-title [内容主题]`
